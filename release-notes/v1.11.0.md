**Added**
- **Control-click a note to file it.** The list's context menu has a Category submenu: every category in use, with the note's own checked, then None, and New Category… for a name that does not exist yet. It takes effect straight away. Organise Notes is still the way to file many notes at once.

**Changed**
- **Saving in Organise Notes no longer blanks the list while it reloads.** It now refreshes only the stored items it changed, instead of rescanning every SSH, GPG and Age key behind a spinner.
