Updating works while a prompt is open. This takes effect from the update after this one, because the version you have now installs this one.

**Fixed**
- **An update finishes even with a prompt open.** If the passphrase prompt, an editor or a save panel was open when an update was ready to restart KeyVault, macOS refused to quit the old copy. The new version was already in place, but the old one kept running and never restarted. The update now quits and restarts KeyVault whatever is open. Until you are on this version, unlock or cancel the passphrase prompt before you click **Update**.

**Developer**
- `SelfUpdater.swift`, shared verbatim with the sibling apps, asks AppKit to quit for the relaunch and, when an open sheet is what refused, finishes the quit itself. A refusal from an app's own delegate still stands. All ten copies changed together.
- The tests' scratch defaults suite starts empty on every run. On macOS 27.2 a suite named by a path keeps reading what its file held when it loaded, so a test run stopped part-way left settings behind that failed four of the five `AppSettingsTests` on every later run.
