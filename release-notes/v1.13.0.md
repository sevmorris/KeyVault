**Added**
- **KeyVault updates itself.** The update prompt now offers **Update and Relaunch**. KeyVault downloads the new version, checks that it's a signed release, replaces itself and reopens, with no disk image to open or app to drag. This starts with the update after this one: to get this version, download it as usual.

**Changed**
- **If KeyVault can't update itself, it says why.** A copy running from the disk image, or one you don't have permission to change, still offers **Download**, with the reason. So does any update that fails, and the installed app is left as it was.
- **Relaunching locks the vault**, as quitting does. Your Keychain access carries over to the new version.

**Developer**
- `SelfUpdater.swift` is shared verbatim with the sibling apps and needs no update feed or new key: it relies on the Developer ID signature that release DMGs and apps already carry.
