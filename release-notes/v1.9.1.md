**Fixed**
- **A first file added before a master passphrase was set is no longer lost.** Add File offered to set the passphrase by closing itself, and the file you had chosen or dropped went with it: the passphrase got set, and the file was never stored. The sheet now asks for the passphrase first, and once it is set carries straight on to the file, still chosen.

**Changed**
- **Secrets are shown as plain text in an ordinary box.** The phosphor screen is gone — the glow, the scanlines, the blinking cursor, and the Secret display setting that chose between green, amber and plain. Notes, API keys, stored files and public keys all read as ordinary text now.
