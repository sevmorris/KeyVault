**Fixed**
- **Selecting a stored file, or a key with long details, no longer pushes the window's contents up and out of it.** The rows describing the selection were held at the height they would need in a window almost no width wide, where every value wraps a character to a line. A file's name, kind, size, date and notes, or an SSH key's fingerprint and path, could then ask for more height than the screen had. They now take their full height whenever there is room, and give way when there is not.
- **SSH keys and API keys have their icons back.** Both named SF Symbols that do not exist, so their rows had drawn no icon since the first release.
